# 免费闲鱼标题文案助手

输入真实商品资料，生成多组闲鱼标题、描述、卖点和搜索词，并标出明显夸大或敏感表达。免费使用，不需要第三方 API Key。

## 用法

直接告诉智能体商品名称、成色、规格、配件、价格和目标买家。例如：“使用 `$easy-xianyu-title-copy-free`，给这件二手相机写 5 个标题和一版实在的描述，缺少的信息列出来。”

这个 Skill 不会自动发布，也不会编造销量、品牌授权或效果。若要读取已有闲鱼草稿，需要安装并启动 [Easy WebBridge](https://github.com/xxjrq/easy-webbridge)，备用地址是 [Gitee](https://gitee.com/xxjrq/easy-webbridge)，并提供已登录浏览器的 `browserId`。
